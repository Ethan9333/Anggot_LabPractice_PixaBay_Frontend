# Pixabay Media Search App

A lightweight single-page web application built with HTML, CSS, and Vanilla JavaScript that enables users to search images and videos using the Pixabay API.

## Features
- Search photos and videos dynamically via the Pixabay API.
- Quick challenge buttons for pre-configured search queries (Rocket Launch, Basketball, Forest, Road Forest).
- Asynchronous data fetching with active loading indicators and error messaging.
- Responsive design tailored for all display sizes.

## Prerequisites & API Key Note

**Important Security Note:**  
This project requires a Pixabay API key to fetch media. To protect secret credentials, local sensitive keys are kept in `config.js`, which is ignored by Git (`.gitignore`). 

When cloning this repository, create a local `config.js` file based on the provided `config.sample.js`.
